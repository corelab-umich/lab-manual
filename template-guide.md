# Templates

Copy the source Markdown templates from the repository's `templates/` directory. That directory is excluded from the published site, so incomplete template front matter does not appear in navigation.

## Operating procedure

`templates/procedure.md` captures the configuration, prerequisites, verified steps, expected outputs, stop/abort behavior, shutdown, and review record. It starts in draft status.

## Experiment record

`templates/experiment.md` captures the run ID, objective, operator, hardware revision, code commit, configuration, dataset location, observations, and analysis version.

## Hardware revision

`templates/hardware-revision.md` captures the build ID, component changes, CAD and wiring references, calibration records, and associated experiments.

## Student handoff

`templates/handoff.md` captures current responsibility, a successor, known working versions, asset locations, unresolved issues, and an access verification checklist.
